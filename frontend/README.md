# StudyMate - Frontend

Frontend da aplicação StudyMate, um sistema acadêmico para organização de disciplinas, tarefas, calendário, frequência, conquistas e progresso do estudante.

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router DOM
- Lucide React

## Como executar o projeto
