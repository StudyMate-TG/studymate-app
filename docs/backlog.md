# Backlog de Produto por Casos de Uso

## Ator: Estudante
### 1. Cadastrar e autenticar usuário
RF01 – Cadastrar usuário / RF02 – Realizar login
- 1.1 Como estudante, quero criar uma conta informando meus dados básicos para utilizar o StudyMate.
- 1.2 Como estudante, quero realizar login com meu e-mail e senha para acessar minhas informações acadêmicas.
- 1.3 Como estudante, quero ser informado quando os dados de autenticação forem inválidos.

### 2. Gerenciar perfil
RF15 – Gerenciar Perfil
- 2.1 Como estudante, quero visualizar os dados do meu perfil.
- 2.2 Como estudante, quero atualizar informações como nome, curso, matrícula e instituição.
- 2.3 Como estudante, quero alterar meus dados pessoais quando necessário.

### 3. Gerenciar período letivo
RF04 – Gerenciar período letivo
- 3.1 Como estudante, quero cadastrar períodos letivos para organizar minhas informações acadêmicas.
- 3.2 Como estudante, quero informar nome, data de início e data de término do período letivo.
- 3.3 Como estudante, quero visualizar meus períodos letivos cadastrados.
- 3.4 Como estudante, quero alterar ou encerrar um período letivo.

### 4. Gerenciar disciplinas
RF05 – Gerenciar disciplinas
- 4.1 Como estudante, quero cadastrar as disciplinas que estou cursando.
- 4.2 Como estudante, quero associar cada disciplina a um período letivo.
- 4.3 Como estudante, quero informar professor, média de aprovação e limite de faltas da disciplina.
- 4.4 Como estudante, quero listar e pesquisar minhas disciplinas.
- 4.5 Como estudante, quero editar ou excluir disciplinas cadastradas.

### 5. Gerenciar horários de aula
RF06 – Gerenciar horários de aula
- 5.1 Como estudante, quero cadastrar os horários de aula de cada disciplina.
- 5.2 Como estudante, quero informar dia da semana, horário de início, horário de término e local da aula.
- 5.3 Como estudante, quero editar ou excluir horários cadastrados.
- 5.4 Como estudante, quero visualizar meus horários acadêmicos de forma organizada.

### 6. Visualizar agenda acadêmica
RF03 – Visualizar agenda acadêmica
- 6.1 Como estudante, quero visualizar em um único local minhas tarefas e avaliações próximas.
- 6.2 Como estudante, quero acompanhar os prazos relacionados às minhas disciplinas.
- 6.3 Como estudante, quero identificar atividades pendentes e compromissos acadêmicos próximos.

### 7. Gerenciar tarefas
RF07 – Gerenciar tarefas
- 7.1 Como estudante, quero cadastrar tarefas vinculadas às minhas disciplinas.
- 7.2 Como estudante, quero informar título, tipo, descrição, prazo e prioridade da tarefa.
- 7.3 Como estudante, quero editar uma tarefa cadastrada.
- 7.4 Como estudante, quero reagendar o prazo de uma tarefa.
- 7.5 Como estudante, quero marcar uma tarefa como concluída.
- 7.6 Como estudante, quero excluir uma tarefa.
- 7.7 Como estudante, quero visualizar minhas tarefas pendentes e concluídas.

### 8. Gerenciar avaliações
RF08 – Gerenciar avaliações
- 8.1 Como estudante, quero cadastrar avaliações vinculadas às disciplinas.
- 8.2 Como estudante, quero informar nome, tipo, nota, peso e data da avaliação.
- 8.3 Como estudante, quero editar uma avaliação cadastrada.
- 8.4 Como estudante, quero excluir uma avaliação quando necessário.
- 8.5 Como estudante, quero visualizar as avaliações de cada disciplina.

### 9. Calcular média
RF09 – Calcular média
- 9.1 Como estudante, quero que o sistema calcule automaticamente minha média com base nas avaliações cadastradas.
- 9.2 Como estudante, quero que a média seja atualizada quando uma avaliação ou nota for alterada.
- 9.3 Como estudante, quero visualizar minha média atual em cada disciplina.

### 10. Registrar e controlar faltas
RF10 – Registrar faltas / RF11 – Controlar faltas
- 10.1 Como estudante, quero registrar faltas vinculadas a uma disciplina.
- 10.2 Como estudante, quero informar a data da falta e a quantidade de aulas perdidas.
- 10.3 Como estudante, quero visualizar o total de faltas registrado em cada disciplina.
- 10.4 Como estudante, quero acompanhar o limite de faltas permitido.
- 10.5 Como estudante, quero ser alertado quando estiver próximo do limite de faltas.

### 11. Visualizar notificações
RF12 – Exibir notificações
- 11.1 Como estudante, quero receber notificações sobre tarefas com prazos próximos.
- 11.2 Como estudante, quero receber avisos sobre avaliações futuras.
- 11.3 Como estudante, quero receber alertas relacionados ao risco de reprovação por média ou faltas.
- 11.4 Como estudante, quero visualizar minhas notificações.
- 11.5 Como estudante, quero marcar uma notificação como lida.

### 12. Acompanhar progresso
RF13 – Acompanhar progresso
- 12.1 Como estudante, quero acumular XP conforme realizo ações no StudyMate.
- 12.2 Como estudante, quero visualizar meu XP total e meu nível atual.
- 12.3 Como estudante, quero acompanhar minha sequência de dias ativos.
- 12.4 Como estudante, quero visualizar minha maior sequência alcançada.
- 12.5 Como estudante, quero que meu progresso seja atualizado automaticamente conforme utilizo o sistema.

### 13. Registrar e visualizar conquistas
RF14 – Registrar e exibir conquistas
- 13.1 Como estudante, quero desbloquear conquistas ao cumprir critérios definidos pelo sistema.
- 13.2 Como estudante, quero visualizar as conquistas que já obtive.
- 13.3 Como estudante, quero visualizar informações sobre cada conquista, como nome, descrição e ícone.
- 13.4 Como estudante, quero que o sistema registre a data em que uma conquista foi obtida.

### 14. Consultar informações offline
RF16 – Consultar dados offline
- 14.1 Como estudante, quero consultar minhas informações acadêmicas mesmo quando estiver sem conexão com a internet.
- 14.2 Como estudante, quero visualizar dados previamente armazenados no dispositivo sem depender do servidor.
- 14.3 Como estudante, quero continuar acessando as funcionalidades compatíveis com o modo offline durante períodos sem conexão.

### 15. Registrar alterações offline
RF17 – Armazenar alterações realizadas offline
- 15.1 Como estudante, quero cadastrar informações mesmo quando estiver sem conexão com a internet.
- 15.2 Como estudante, quero editar dados disponíveis localmente enquanto estiver offline.
- 15.3 Como estudante, quero que as alterações realizadas sem conexão sejam armazenadas no dispositivo.
- 15.4 Como estudante, quero que minhas alterações permaneçam disponíveis até que possam ser sincronizadas com o servidor.

### 16. Sincronizar dados com o servidor
RF18 – Sincronizar dados com o servidor
- 16.1 Como estudante, quero que as alterações realizadas offline sejam enviadas ao servidor quando a conexão com a internet estiver disponível.
- 16.2 Como estudante, quero que a sincronização ocorra sem perder as alterações realizadas anteriormente.
- 16.3 Como estudante, quero continuar utilizando o aplicativo caso uma tentativa de sincronização falhe temporariamente.
- 16.4 Como estudante, quero que as operações pendentes sejam processadas quando a comunicação com o servidor for restabelecida.
