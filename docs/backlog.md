# Backlog de Produto por Casos de Uso

## Ator: Estudante
### 1. Cadastrar e autenticar usuário
RF01 – Cadastrar usuário / RF02 – Realizar login
- 1.1 Como estudante, quero criar uma conta informando meus dados básicos para utilizar o StudyMate.
- 1.2 Como estudante, quero realizar login com meu e-mail e senha para acessar minhas informações acadêmicas.
- 1.3 Como estudante, quero ser informado quando os dados de autenticação forem inválidos.
- 1.4 Como estudante, quero acessar somente as informações vinculadas à minha conta.

### 2. Gerenciar perfil
RF15 – Gerenciar Perfil
- 2.1 Como estudante, quero visualizar os dados do meu perfil.
- 2.2 Como estudante, quero atualizar informações como nome, curso, matrícula e instituição.
- 2.3 Como estudante, quero alterar meus dados pessoais quando necessário.

### 3. Gerenciar período letivo
RF04 – Gerenciar período letivo
- 3.1 Como estudante, quero cadastrar períodos letivos para organizar minhas informações acadêmicas.
- 3.2 Como estudante, quero informar nome, data de início e data de término do período letivo.
- 3.3 Como estudante, quero visualizar meus períodos letivos cadastrados.
- 3.4 Como estudante, quero editar informações de um período letivo.
- 3.5 Como estudante, quero excluir um período letivo quando necessário.

### 4. Gerenciar disciplinas
RF05 – Gerenciar disciplinas
- 4.1 Como estudante, quero cadastrar as disciplinas que estou cursando.
- 4.2 Como estudante, quero associar cada disciplina a um período letivo.
- 4.3 Como estudante, quero informar professor, média de aprovação e limite de faltas da disciplina.
- 4.4 Como estudante, quero listar e pesquisar minhas disciplinas.
- 4.5 Como estudante, quero editar ou excluir disciplinas cadastradas.

### 5. Gerenciar horários de aula
RF06 – Gerenciar horários de aula
- 5.1 Como estudante, quero cadastrar os horários de aula de cada disciplina.
- 5.2 Como estudante, quero informar dia da semana, horário de início, horário de término e local da aula.
- 5.3 Como estudante, quero visualizar os horários cadastrados para minhas disciplinas.
- 5.4 Como estudante, quero editar horários de aula cadastrados.
- 5.5 Como estudante, quero excluir horários de aula quando necessário.

### 6. Visualizar agenda acadêmica
RF03 – Visualizar agenda acadêmica
- 6.1 Como estudante, quero visualizar em um único local meus horários de aula, tarefas e avaliações.
- 6.2 Como estudante, quero acompanhar os prazos e datas relacionados às minhas atividades acadêmicas.
- 6.3 Como estudante, quero identificar atividades pendentes e compromissos acadêmicos próximos.
- 6.4 Como estudante, quero consultar meus horários de aula de forma organizada dentro da agenda.

### 7. Gerenciar tarefas
RF07 – Gerenciar tarefas
- 7.1 Como estudante, quero cadastrar tarefas vinculadas às minhas disciplinas.
- 7.2 Como estudante, quero informar título, tipo, descrição, prazo e prioridade da tarefa.
- 7.3 Como estudante, quero visualizar minhas tarefas pendentes e concluídas.
- 7.4 Como estudante, quero editar uma tarefa cadastrada.
- 7.5 Como estudante, quero reagendar o prazo de uma tarefa.
- 7.6 Como estudante, quero marcar uma tarefa como concluída.
- 7.7 Como estudante, quero reabrir uma tarefa concluída quando necessário.
- 7.8 Como estudante, quero excluir uma tarefa.

### 8. Gerenciar avaliações
RF08 – Gerenciar avaliações
- 8.1 Como estudante, quero cadastrar avaliações vinculadas às minhas disciplinas.
- 8.2 Como estudante, quero informar nome, tipo, nota, peso e data da avaliação.
- 8.3 Como estudante, quero visualizar as avaliações cadastradas em cada disciplina.
- 8.4 Como estudante, quero editar uma avaliação cadastrada.
- 8.5 Como estudante, quero excluir uma avaliação quando necessário.

### 9. Calcular média
RF09 – Calcular média
- 9.1 Como estudante, quero que o sistema calcule automaticamente minha média com base nas avaliações cadastradas e seus respectivos pesos.
- 9.2 Como estudante, quero que avaliações ainda sem nota não sejam consideradas no cálculo da média.
- 9.3 Como estudante, quero que minha média seja atualizada quando uma avaliação ou nota for cadastrada, alterada ou excluída.
- 9.4 Como estudante, quero visualizar minha média atual em cada disciplina.

### 10. Registrar presenças e faltas
RF10 – Registrar presenças e faltas / RF11 – Acompanhar frequência e limite de faltas
- 10.1 Como estudante, quero registrar minha presença em uma aula vinculada a uma disciplina.
- 10.2 Como estudante, quero registrar faltas vinculadas a uma disciplina.
- 10.3 Como estudante, quero associar os registros de presença e falta à respectiva data.
- 10.4 Como estudante, quero informar a quantidade de aulas perdidas ao registrar uma falta.
- 10.5 Como estudante, quero visualizar meus registros de presenças e faltas.
- 10.6 Como estudante, quero visualizar o total de faltas acumuladas em cada disciplina.
- 10.7 Como estudante, quero acompanhar o limite de faltas permitido para cada disciplina.
- 10.8 Como estudante, quero identificar quando minha quantidade de faltas estiver próxima do limite permitido.

### 11. Consultar notificações
RF12 – Consultar notificações
- 11.1 Como estudante, quero receber notificações sobre tarefas com prazos próximos.
- 11.2 Como estudante, quero receber avisos sobre avaliações futuras.
- 11.3 Como estudante, quero receber alertas relacionados ao risco de reprovação por média ou faltas.
- 11.4 Como estudante, quero visualizar minhas notificações.
- 11.5 Como estudante, quero marcar uma notificação como lida.

### 12. Acompanhar progresso
RF13 – Acompanhar progresso
- 12.1 Como estudante, quero receber XP ao realizar atividades acadêmicas elegíveis no StudyMate.
- 12.2 Como estudante, quero receber XP pela conclusão de tarefas conforme as regras de gamificação.
- 12.3 Como estudante, quero receber XP pelo registro de presença conforme as regras de gamificação.
- 12.4 Como estudante, quero visualizar meu XP acumulado.
- 12.5 Como estudante, quero visualizar meu nível atual.
- 12.6 Como estudante, quero acompanhar minha sequência de dias de atividade.
- 12.7 Como estudante, quero que meu progresso seja atualizado automaticamente conforme as atividades elegíveis forem registradas.

### 13. Acompanhar conquistas
RF14 – Acompanhar conquistas
- 13.1 Como estudante, quero desbloquear conquistas ao cumprir critérios previamente definidos pelo sistema.
- 13.2 Como estudante, quero visualizar as conquistas que já obtive.
- 13.3 Como estudante, quero visualizar as conquistas ainda não obtidas, quando aplicável.
- 13.4 Como estudante, quero visualizar informações relacionadas a cada conquista.
- 13.5 Como estudante, quero que as conquistas obtidas sejam representadas visualmente por medalhas ou badges.
- 13.6 Como estudante, quero que o sistema registre quando cada conquista foi desbloqueada.

### 14. Consultar tarefas offline
RF16 – Consultar tarefas offline
- 14.1 Como estudante, quero consultar minhas tarefas mesmo quando estiver sem conexão com a internet.
- 14.2 Como estudante, quero visualizar tarefas previamente armazenadas no dispositivo sem depender do servidor.
- 14.3 Como estudante, quero visualizar também as alterações locais ainda não sincronizadas.
- 14.4 Como estudante, quero ser informado quando não houver dados locais disponíveis para consulta.

### 15. Realizar alterações em tarefas offline
RF17 – Realizar alterações em tarefas offline
- 15.1 Como estudante, quero cadastrar tarefas mesmo quando estiver sem conexão com a internet.
- 15.2 Como estudante, quero editar tarefas disponíveis localmente enquanto estiver offline.
- 15.3 Como estudante, quero concluir tarefas enquanto estiver offline.
- 15.4 Como estudante, quero reabrir tarefas enquanto estiver offline.
- 15.5 Como estudante, quero excluir tarefas enquanto estiver offline.
- 15.6 Como estudante, quero que as alterações realizadas sem conexão sejam armazenadas localmente.
- 15.7 Como estudante, quero que as operações realizadas offline permaneçam pendentes até serem sincronizadas com o servidor.
- 15.8 Como estudante, quero ser informado caso uma alteração não possa ser registrada corretamente.

### 16. Sincronizar tarefas com o servidor
RF18 – Sincronizar dados com o servidor
- 16.1 Como estudante, quero que as operações realizadas offline sejam enviadas ao servidor quando a conexão com a internet estiver disponível.
- 16.2 Como estudante, quero que as tarefas armazenadas localmente sejam atualizadas com informações recebidas do servidor.
- 16.3 Como estudante, quero que uma mesma operação não seja aplicada mais de uma vez em caso de reenvio.
- 16.4 Como estudante, quero continuar utilizando o aplicativo caso uma tentativa de sincronização falhe temporariamente.
- 16.5 Como estudante, quero que operações que não puderem ser sincronizadas permaneçam disponíveis para uma nova tentativa.
- 16.6 Como estudante, quero que uma operação seja considerada sincronizada somente após a confirmação do servidor.

### 17. Consultar estado da sincronização
RF19 – Consultar estado da sincronização
- 17.1 Como estudante, quero visualizar quando minhas informações estiverem sincronizadas com o servidor.
- 17.2 Como estudante, quero identificar quando existirem operações pendentes de sincronização.
- 17.3 Como estudante, quero ser informado quando ocorrer uma falha durante a sincronização.
- 17.4 Como estudante, quero que operações com falha permaneçam disponíveis para nova tentativa.
- 17.5 Como estudante, quero acompanhar o estado da sincronização para saber se minhas alterações já foram enviadas ao servidor.
